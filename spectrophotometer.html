Chapter 3: Spectrophotometer, CIELAB Values & Delta-E Tolerances

ऑफ़सेट प्रिंटिंग में एडवांस्ड कलर मैनेजमेंट, CIELAB स्पेस वेक्टर मैकेनिक्स, डेल्टा-ई 2000 सहनशीलता और स्पेक्ट्रोफोटोमीटर लाइटिंग स्टैंडर्ड्स का विस्तृत तकनीकी दस्तावेज।

1. Optical Geometry: 45/0 vs. Diffuse/8 Degree Integrating Sphere

हाई-स्पीड प्रेस (जैसे Heidelberg CX 104) पर कलर माप के लिए सेंसर ऑप्टिक्स का चयन प्रिंट सब्सट्रेट की चमक (Gloss) पर निर्भर करता है:

Geometry Mode / जियोमेट्री English Technical Specification हिंदी तकनीकी विवरण
45/0 Degree Geometry Mimics human visual response by eliminating surface specular gloss; ideal for standard matte and gloss paper stocks. सरफेस स्पेक्युलर ग्लोस को हटाकर मानव आँख के देखने के तरीके को दोहराती है; मैट और ग्लोस पेपर के लिए आदर्श।
d/8 Integrating Sphere Captures total reflectance including specular (SPIN) or excludes it (SPEX); critical for metallics, foils, and high-gloss boards. कुल रिफ्लेक्शन (SPIN/SPEX) को कैप्चर करती है; मेटालिक्स, फॉइल और हाई-ग्लोस बोर्ड्स के लिए अत्यंत आवश्यक।
Practical Experiment / प्रायोगिक दृष्टिकोण:

English: When printing metallic cartons, 45/0 sensors yield false color data due to unmeasured specular scatter. Always switch to d/8 Sphere with SPEX mode enabled.

हिंदी: मेटालिक कार्टन प्रिंटिंग में 45/0 सेंसर गलत कलर डेटा दे सकता है क्योंकि यह स्पेक्युलर स्कैटर को छोड़ देता है। ऐसे सब्सट्रेट्स पर हमेशा SPEX मोड के साथ d/8 स्फीयर का उपयोग करें।

2. CIELAB Color Space Vector Mechanics (L*, a*, b*)

L* Axis (Lightness)

English: Represents psychometric lightness from 0 (black) to 100 (white). Directly controlled by ink film thickness adjustments on press ink keys.

हिंदी: 0 (काला) से 100 (सफेद) तक लाइटनैस दर्शाता है। प्रेस इंक कीज़ पर फिल्म मोटाई बदलकर इसे नियंत्रित किया जाता है।

a* Axis (Red-Green)

English: Defines the green-to-red opponent axis. Shifts here indicate pigment strength imbalances or pigment hue angle drift.

हिंदी: हरे से लाल अक्ष को परिभाषित करता है। इसमें बदलाव पिगमेंट स्ट्रेंथ या ह्यू एंगल में असंतुलन को दर्शाता है।

b* Axis (Blue-Yellow)

English: Defines the blue-to-yellow opponent axis. Highly sensitive to substrate Optical Brightening Agents (OBA) and yellow ink pigment variations.

हिंदी: नीले से पीले अक्ष को परिभाषित करता है। सब्सट्रेट के OBA (ऑप्टिकल ब्राइटनिंग एजेंट) और येलो इंक से अत्यधिक प्रभावित होता है।

3. Evolution to Delta E 2000 (dE00) Tolerances

Mathematical & Visual Correction:

English: Unlike dE76 (which assumes uniform Euclidean distance), dE2000 introduces interactive weighting functions for lightness (SL), chroma (SC), and hue (SH), alongside a rotational term (Rt) to resolve blue-region perceptual anomalies.

हिंदी: dE76 के विपरीत (जो सीधी यूक्लिडियन दूरी मानता है), dE2000 लाइटनैस (SL), क्रोमा (SC) और ह्यू (SH) के लिए वेटिंग फंक्शन और ब्लू-रीजन की विजुअल त्रुटियों को ठीक करने के लिए रोटेशनल टर्म (Rt) जोड़ता है।

Press-Floor Acceptance Thresholds:

English: Standard corporate packaging requires dE00 below 2.0. High-end pharma, cosmetics, and luxury folding cartons enforce strict limits below 1.5.

हिंदी: स्टैंडर्ड कॉर्पोरेट पैकेजिंग के लिए dE00 मान 2.0 से कम होना चाहिए। हाई-एंड फार्मा, कॉस्मेटिक्स और लग्जरी कार्टन के लिए सीमा 1.5 से कम रखी जाती है।

4. Metamerism Index (MI) & Spectrophotometer M-Standards

M1 Mode (D50 + UV)

Includes ultraviolet energy to correctly excite OBA-treated substrates, serving as the modern universal press standard.

M2 Mode (UV-Cut)

Eliminates UV component to evaluate the base substrate color without optical brightener fluorescence interference.

M3 Mode (Polarized)

Enables polarizing filters to eliminate wet ink specular reflection, matching wet print density to dry sheet readings.

Color Metrology Logic Script (जावास्क्रिप्ट लॉजिक)

// Spectrophotometer Delta-E 2000 & Chroma Verification Model
function evaluateColorTolerance(dE2000Value, jobCategory) {
    const threshold = jobCategory === 'PHARMA' ? 1.5 : 2.0;
    if (dE2000Value <= threshold) {
        return { status: "APPROVED", action: "Proceed with production run." };
    } else {
        return { status: "REJECTED", action: "Adjust ink key densities or check pigment formulation." };
    }
}
console.log(evaluateColorTolerance(1.3, 'PHARMA'));
